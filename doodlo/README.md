# Doodlo — animated drawing playground

An independent portfolio concept inspired by the visual reference at https://3dss.w-nest.net/. The mascot and toy scene are original SVG artwork with CSS animations, not the premium template or its 3D assets.

Four sections: Home, Drawing Studio, How to Play, Gallery. Supports mouse and touch drawing, adjustable brush size, colors, eraser, undo and redo, local gallery storage, and PNG export. No accounts, external dependencies, or server. All drawing data stays in the browser unless the visitor downloads it.

Static deployment through GitHub Pages: index.html.
