# Patchwork — interactive portfolio concept

An independent front-end prototype inspired by the Patchwork visual reference at https://3dss.w-nest.net/ and the four generated design mockups. It does not contain the premium template or its original source files. All interface copy, SVG illustrations, and animation code are implemented directly in index.html.

Features: animated isometric factory, cursor parallax, six responsive sections, selectable use-case/story/guide cards, a local interactive task board, and a 12-second animated canvas walkthrough with browser-side video export where supported. Stories are illustrative examples, not verified customer claims. The prototype has no server or multiuser backend.

Deployment: static GitHub Pages, no build or CDN dependencies.
