# THE CITY OPENS

Standalone GitHub Pages demo: index.html. No build step. Original film and attribution preserved; the static page uses native browser JavaScript. React integration source is in components/ui/scroll-locked-video-hero.tsx with a demo.tsx example. It requires React and TypeScript only, no extra packages. To use with an existing shadcn/Vite app, place it in src/components/ui if the @ alias resolves to src; otherwise use the configured components alias. Tailwind is optional for this inline-styled component. For a fresh shadcn app, use npx shadcn@latest init -t vite. The demo is a full-screen single-scene experience, with keyboard and slider input in addition to wheel/touch. The video loads from the original CDN and needs internet.
